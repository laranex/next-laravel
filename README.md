Next Laravel organizes a Laravel application into modules that own their controllers, form requests, features, operations and jobs, with an Artisan generator for every unit and automatic discovery of route files under `routes/web` and `routes/api`. Built for humans and AI agents.

## Documentation

Full documentation, including installation, usage and the AI agent skill, lives at **[laranex.vercel.app/next-laravel](https://laranex.vercel.app/next-laravel)**.
